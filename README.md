### Como Instalar 
1- Clonar o Respositório:
```bash
git clone https://github.com/khsd098/Projeto-integrador
```
2- Entrando na Pasta:
```bash
cd Projeto-integrador
```
3- Instalanado as Dependência:
```bash
npm install
```
4- Executando o Projeto:
```
npm run dev
```
